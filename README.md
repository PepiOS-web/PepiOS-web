## Featured projects

### 🖥️ HomeLab

A secure, observable, and recoverable self-hosted infrastructure built from a repurposed laptop.

**Technologies:** Ubuntu Server, Docker Compose, Prometheus, Grafana, Caddy, AdGuard Home, Tailscale, ESPHome, and systemd.

Key features:

- Internal HTTPS and local DNS
- Secure remote access
- System and network monitoring
- Automated alerts
- Daily verified backups
- Weekly encrypted off-device backups
- Recovery testing
- Centralized operational portal
- ESP8266 environmental sensor integration
- Temperature and humidity history

[View repository](https://github.com/PepiOS-web/Home-Lab)
